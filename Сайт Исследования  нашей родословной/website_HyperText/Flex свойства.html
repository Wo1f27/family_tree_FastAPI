padding - [паэдинг - как сущ. набивка, как прилаг -дополнительный ]со всех сторон. В CSS — это внутренний отступ, который создаёт пространство между содержимым элемента и его границей (border).

    Разберём три ключевые группы свойств:

  • Направление оси (flex-direction) — по горизонтали, по вертикали, в обратную сторону.
  • Выравнивание по главной оси (justify-content).
  • Выравнивание по поперечной оси (align-items и align-content) — по вертикали или в пределах нескольких строк.
flex-direcction
👉 Главное, что нужно запомнить: flex-direction меняет основную ось (main axis), и все остальные свойства (justify-content, align-items) начинают работать относительно этой оси.СМ.Инструмент разработчика...какая ось...
  1. flex-direction: row; - по умолчанию — в строку слева направо
  2. flex-direction: row-reverse; в строку справа налево
  3. а если flex-direction: column - то выравниваются по вертикали сверху вниз:
  4. flex-direction: column-reverse; в колонку снизу вверх
justify-content
[ждустив контент] перевод = растянуть контент по основной оси, т.е если У этого свойства есть 6 режимов
  • justify-content: space-aurond [спейс эйараунд] = растянуть равномерно; Абсолютно равные отступы между всеми элементами
  • juatify-cjntent: flex-start (в начало);Элементы прижаты к началу оси (слева или сверху)
  • center (по центру);Все элементы выравниваются по центру оси
  • flex-end (в конец);Элементы прижаты к концу оси (справа или снизу)
  • space-between [спейс бетвин] = (обычно в хедерах, футерах, навигации- когда надо два блока по бокам и сто-то посередине) растянуть с равными расстояниями;Первый элемент у начала, последний — у конца, между остальными равные отступы
  • justify-content: space-evenly;Абсолютно равные отступы между всеми элементами, включая края

Теперь рассмотрим выравнивание перпендикулярно основной оси.

align-items([эйлайн айтемс] перевод= центрирование по вертикали):управляет выравниванием флекс-элементов в пределах одной строки/колонки;
align-content - работает, когда у вас несколько строк (например, при flex-wrap: wrap) и управляет выравниванием всей группы строк.
align-items[эйлайн айтемс]-это выравнивание флекс-элементов вдоль поперечной оси (обычно по вертикали), внутри одной линии раскладки. То есть работает в пределах одной «флекс-строки».
  1. align-items: stretch; ([стреч]растянуть на всю высоту, с тектом обычно не работаем);/* по умолчанию — элементы растягиваются по высоте */
  2. align-items: flex-start; /* прижаты к началу поперечной оси */(в верхнюю часть);
  3. align-items: flex-end; /* прижаты к концу */(в нижнюю часть);
  4. align-items: center; /* по центру */работает, когда у вас несколько строк (например, при flex-wrap: wrap) и управляет выравниванием всей группы строк.
  5. align-items: baseline; [безлайн](базовая линия);/* по базовой линии текста */
Смотри показано на картинке

Здесь важно уточнить два нюанса:

  1. stretch не сработает, если у флекс-элемента явно задана высота height (или width при flex-direction: column). Растягиваться просто некуда — браузер следует заданному размеру
  2. baseline имеет смысл только при наличии текста и особенно заметен, когда шрифты в элементах различаются по размеру. Если контент одинаковый, визуальной разницы с flex-start почти не будет.
Дальше рассмотрим align-content — это свойство управляет выравниванием групп флекс-элементов внутри контейнера по поперечной оси.
