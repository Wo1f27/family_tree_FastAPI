Поддержка фрагментов и расширений Emmet встроена прямо в код Visual Studio, никаких расширений не требуется. Emmet 2.0 поддерживает большинство действий Emmet , включая расширение сокращений и фрагментов Emmet. Как расширить сокращения
Например, введём в HTML-файле такую конструкцию:

ul>li*5

Нажмём клавишу Tab. Эта конструкция будет преобразована в следующий код:
<ul>
			   <li></li>
			   <li></li>
			   <li></li>
			   <li></li>
			   <li></li>
			   </ul>

Если ввести в редакторе a и нажать на Tab, то в код будет вставлена конструкция a href="">/a> - курсор будет размещён внутри кавычек, позволяя тут же ввести значение атрибута href.
Если ввести в редакторе ul>li*5>a.Link и нажать Tab. Эта конструкция будет преобразована в следующий код:
<ul>
				<ul class="li alink"></ul>
				<ul class="li alink"></ul>
				<ul class="li alink"></ul>
				<ul class="li alink"></ul>
				<ul class="li alink"></ul>

Тег <a> устанавливает ссылку или якорь. Якорем называется закладка внутри страницы, которую можно указать в качестве цели ссылки. При использовании ссылки, которая указывает на якорь, происходит переход к закладке внутри веб-страницы. Тег <a> является одним из важных элементов HTML и предназначен для создания ссылок. В зависимости от присутствия атрибутов name или href тег <a>
