Теги выделения текста

Иногда необходимо выделить слово, словосочетание, предложение или целый участок текста, чтобы привлечь внимание читателя или поискового робота. А для того, чтобы это сделать, можно выделить фрагмент жирным, курсивом, или подчеркнуть. Аккуратнее с подчеркиванием текста: принято по стандартам, что подчеркнуты гиперссылки, и многие пользователи уже настолько к этому привыкли, что когда видят подчеркнутый текст, то им хочется «кликнуть» по этому участку текста, ожидая перейти на другую страницу.

Тег hr> определяет горизонтальную линию, которая вставляет разрыв строки до и после себя и занимает всю доступную ширину. По умолчанию цвет линии серый, а толщина — 1px.
hr style="border: 0; height: 2px; background-color: #333;"> — формирует горизонтальную линию тёмно-серого оттенка высотой в 2 пикселя, лишённую стандартных границ. hr style="border: none; border-top: 2px dashed #4CAF50; width: 50%;"> — создаёт пунктирную горизонтальную линию. для стандартизации стилей рекомендуется добавить класс, например, line. Это позволит применять одинаковые стили к нескольким элементам с одинаковым классом. Смотри в сайт... ссылка не видно

Тег <small> Уменьшает размер шрифта на единицу по отношению к обычному тексту.

Тег<sub> Используется для создания нижних индексов. Сдвигает текст ниже уровня строки, уменьшая его размер.

Тег <ins> Выделяет текст в новой версии документа, подчёркивая его.

Тег pre> в HTML (от англ. preformatted text) определяет блок предварительно отформатированного текста. Он сохраняет все пробелы и разрывы строк, в отличие от того, как браузеры по умолчанию показывают любое количество идущих подряд пробелов как один. Содержимое тега отображается в браузере моноширинным шрифтом (шрифт, в котором все знаки имеют одинаковую ширину). По умолчанию браузер самостоятельно меняет шрифт внутри тега на моноширинный — например, на Courier или Menlo (в зависимости от операционной системы и браузера).Важно: сам по себе тег 

 не семантический — он влияет только на внешний вид текста, но не помогает поисковым системам понять его смысл. Есть теги, которые можно использовать внутри 
, и они помогут скринридерам и поисковым системам определить, что за контент лежит внутри. Примеры таких тегов:  — для записи кода,  — для записи вывода результатов скриптов (например, сообщения об ошибках),  — для обозначения ввода пользователя (например, комбинации клавиш).

<p>

				
Тег <p> - Разбивка текста на параграфы. Тег
					<p> является блочным элементом, всегда начинается с новой строки, абзацы
					текста идущие
					друг за другом разделяются между собой отбивкой. Величиной отбивки можно управлять с помощью
					стилей. Если
					закрывающего тега нет, считается, что конец абзаца совпадает с началом следующего блочного
					элемента. 

					
У тега <p> есть атрибуты (свойства)

					Атрибуты:

					ALIGN - определяет способ горизонтального выравнивания параграфа .
					Возможные значения: left, center, right, justify. Это соответственно по левому краю, по центру,
					по правому
					краю, и по ширине .По умолчанию имеет значение left.

					Приведу пример:

					Если внутри тела документа написать следующее:


					тег <p align="center"> Этот параграф по центру /p>

					тег p align="left"> Этот по левому краю/p(закрыть тег)

					тег p Этот тоже по левому (т.к. по умолчанию) /p(закрыть тег)

					тег p align="right"> Этот по правому краю/p(закрыть тег)

					тег p align="justify"> В этом параграфе текст будет выравниваться по ширине (одновременно
					по левому и
					правому краям документа). Не понимающие justify браузеры будут выравнивать текст по левому
					краю/p(закрыть
					тег)

					Примечание: следите чтобы содержимое в кавычках было написано без пробелов, т.е. тег p
					align="right"> а не
					тег p align=" right "> иначе не будет работать!
