Глобальные атрибуты
Атрибут Описание Значение
accesskey Используется для создания сочетания клавиш для доступа к элементу. Цифры от 0 до 9 или латинские буквы (a-z)
class Используется для определения имя класса, через которое можно обратиться к нему для стилевого оформления Латинские буквы (A–Z, a–z), цифры (0–9), символ дефиса (-) и нижнего подчеркивания (_) (не должно начинаться с цифры)
contenteditable Наличие этого атрибута означает, что пользователь может редактировать содержимое элемента. true - режим редактирования включен
false - режим редактирование выключен
contextmenu Создает контекстное меню для элемента (меню показывается, когда пользователь кликает на элемент). Идентификатор меню, созданного с помощью тега <menu>
data-* Определяет группу атрибутов (атрибуты пользовательских данных), которые позволяют обмениваться служебной информацией между HTML и его DOM представлением. Любое значение, которое описывает намерение пользователя.
dir Определяет направление текста в элементе (слева направо или справа налево) ltr - left to right ( слева направо)
rtl - right to left (справа налево)
auto - направление текста определяется браузером
draggable Указывает, можно ли перетаскивать элемент используя Drag and Drop API It is used to define if an element is draggable or not. true - перетаскивание элемента разрешено
false- перетаскивание элемента запрещено
dropzone Определяет, что делать с перетаскиваемыми пользователем данными copy (по умолчанию)- скопировать переносимый элемент в принимающий элемент.
link - создать в элементе ссылку на первоисточник, откуда он был перемещен.
move - перенести элемент в принимающий элемент, удалив его из предыдущего
hidden Указывает, что содержимое элемента более не актуально и должно быть скрыто от просмотра. Пустая строка или имя атрибута (hidden). Атрибут может быть указан без значения.
id Устанавливает уникальный идентификатор для элемента, к которому можно обратиться при созданиии ссылок на него, исполнении скриптов или применении стилей. Только английские буквы (верхнего и нижнего регистра), цифры, а также символы «-» (дефис) и «_» (подчёркивание)
lang Указывает, какой язык используется для текста внутри элемента. Коды языков
spellcheck Указывает браузеру проверять ли текст на наличие орфографических ошибок. true - элемент должен проверяться
false -элемент не должен проверяться
style Определяет стиль элемента с помощью правил CSS. Свойства CSS со своим значением
tabindex Определяет порядок получения фокуса при переходе между элементами с помощью клавиши Tab. Любое целое число
title Содержит дополнительную информацию о содержимом элемента (отображается в виде всплывающей текстовой подсказки при наведении курсора мыши). Произвольный текст
translate Указывает, следует ли переводить текстовое содержимое и значение атрибутов элемента. yes - перевести
no - не переводить
