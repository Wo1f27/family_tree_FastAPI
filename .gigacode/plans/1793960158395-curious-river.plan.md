# План: Гибридный сайт Family Tree (Jinja2 + FastAPI REST API)

## Контекст

**Цель:** Превратить статический HTML-сайт в серверный рендеринг с Jinja2 + REST API для интерактива. Запуск через `.exe` (PyInstaller), тот же SQLite, что и desktop-приложение.

**Текущее состояние:**
- Desktop: полностью рабочий (`models.py`, `database.py`, `gui.py`, `dates.py`)
- FastAPI: каркас-заглушки (`src/familytree/` — все файлы `Stub — to be implemented`)
- HTML-сайт: `Сайт Исследования  нашей родословной/` — 7+ страниц с CSS/JS/картинками
- pyproject.toml: fastapi, sqlalchemy, pydantic, alembic, python-jose, pwdlib, Python 3.13

**Страницы сайта:**
| Страница | Назначение |
|---|---|
| index.html | Главная — введение, история |
| Фамилии.html | Список фамилий → страницы семей |
| Гончаровы.html / Кондрашовы.html | Страницы семей с карточками персон |
| doc.html | Документы (справки, архив) |
| gallery.html | Галерея фотографий |
| guest.html | Гостевая книга |
| О проекте.html | Описание, контакты |

#### A.4. main.py — базовая настройка

- **`src/familytree/main.py`** — настроить FastAPI с CORS, статикой, шаблонами:
  ```python
  from fastapi import FastAPI
  from fastapi.middleware.cors import CORSMiddleware
  from fastapi.staticfiles import StaticFiles
  from fastapi.templating import Jinja2Templates
  from pathlib import Path
  from familytree.core.database import engine, init_db
  from familytree.core.config import settings, get_db_path

  app = FastAPI(title="Family Tree Web", version="0.1.0")

  # CORS
  app.add_middleware(
      CORSMiddleware,
      allow_origins=["*"],
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )

  # Static files
  static_dir = Path(__file__).parent / "static"
  app.mount("/static", StaticFiles(directory=str(static_dir)), name="static")

  # Templates
  templates = Jinja2Templates(directory=str(Path(__file__).parent / "templates"))

  # Init DB
  init_db()

  @app.get("/health")
  async def health_check():
      return {"status": "ok"}
  ```

### Фаза C: REST API — CRUD persons

**Цель:** Реализовать API для управления персонами.

#### C.1. Pydantic схемы

- **`src/familytree/schemas/person.py`** — создать:
  ```python
  from pydantic import BaseModel, Field
  from typing import Optional
  from datetime import date

  class PersonBase(BaseModel):
      first_name: str
      last_name: str
      middle_name: Optional[str] = None
      maiden_name: Optional[str] = None
      gender: str  # male/female/other
      birth_year: Optional[int] = None
      birth_month: Optional[int] = None
      birth_day: Optional[int] = None
      birth_approx: bool = False
      death_year: Optional[int] = None
      death_month: Optional[int] = None
      death_day: Optional[int] = None
      death_approx: bool = False
      place_of_birth: Optional[str] = None
      place_of_death: Optional[str] = None
      burial_place: Optional[str] = None
      death_cause: Optional[str] = None
      biography: Optional[str] = None
      archive_records: Optional[str] = None

  class PersonCreate(PersonBase):
      pass

  class PersonUpdate(BaseModel):
      first_name: Optional[str] = None
      last_name: Optional[str] = None
      # ... все поля Optional

  class PersonResponse(PersonBase):
      id: int
      created_at: Optional[date] = None
      updated_at: Optional[date] = None
      class Config:
          from_attributes = True
  ```

#### C.2. Репозиторий

- **`src/familytree/infrastructure/db/repositories/person_repo.py`** — CRUD операции:
  ```python
  class PersonRepository:
      def __init__(self, session: Session):
          self.session = session

      def get_all(self) -> list[Person]: ...
      def get_by_id(self, person_id: int) -> Person | None: ...
      def create(self, person: PersonCreate) -> Person: ...
      def update(self, person_id: int, data: PersonUpdate) -> Person | None: ...
      def delete(self, person_id: int) -> bool: ...
      def get_surnames(self) -> list[str]: ...
      def search(self, query: str) -> list[Person]: ...
  ```

#### C.3. Endpoints

- **`src/familytree/api/v1/endpoints/persons.py`** — маршруты:
  ```python
  router = APIRouter(prefix="/api/v1/persons", tags=["persons"])

  @router.get("/", response_model=list[PersonResponse])
  def list_persons(repo: PersonRepository = Depends(get_repo)):
      return repo.get_all()

  @router.get("/{person_id}", response_model=PersonResponse)
  def get_person(person_id: int, repo: PersonRepository = Depends(get_repo)):
      person = repo.get_by_id(person_id)
      if not person: raise HTTPException(404)
      return person

  @router.post("/", response_model=PersonResponse, status_code=201)
  def create_person(data: PersonCreate, repo: PersonRepository = Depends(get_repo)):
      return repo.create(data)

  @router.put("/{person_id}", response_model=PersonResponse)
  def update_person(person_id: int, data: PersonUpdate, repo: PersonRepository = Depends(get_repo)):
      ...

  @router.delete("/{person_id}", status_code=204)
  def delete_person(person_id: int, repo: PersonRepository = Depends(get_repo)):
      ...
  ```

## Верификация

1. `python -m uvicorn familytree.main:app --reload` — сервер запускается
2. `http://127.0.0.1:8000/` — главная страница
3. `http://127.0.0.1:8000/surnames` — список фамилий (из БД)
4. `http://127.0.0.1:8000/family/Гончаровы` — страница семьи
5. `curl http://127.0.0.1:8000/api/v1/persons` — JSON список персон
6. `curl -X POST http://127.0.0.1:8000/api/v1/persons -d '...'` — создание персоны
7. Открыть desktop-приложение — те же данные в БД
8. `pyinstaller family_tree_web.spec` — сборка .exe
