margin-bottom: 15px; устанавливает внешний отступ внизу элемента. Положительное значение увеличивает расстояние между соседними элементами, тогда как отрицательное - сокращает. Величину нижнего отступа можно указывать в пикселах (px), процентах (%) или других допустимых для CSS единицах. Можно вместо четырех свойств задать одно ... margin-top: отступ сверху
margin-bottom: отступ снизу
margin-left: отступ слева
margin-right: отступ справа
style> div{ margin-top: 30px; /* отступ сверху */ margin-left: 25px; /* отступ слева */ margin-right: 20px; /* отступ справа */ margin-bottom: 15px; /* отступ снизу */ border: 3px solid red; /* граница */ } /style>

Line-height (лайн хайт)в CSS — это свойство, которое задаёт интерлиньяж — расстояние между базовыми линиями соседних строк текста. Базовая линия — воображаемая линия, на которой располагаются основания большинства букв (без учёта нижних выносных элементов, как у букв «у», «д», «р»).
